# Fix Node.js runtime bundling for local builds

**Date:** 2026-06-17  
**Type:** Bug Fix

## Problem

When building locally with `npm run dist:win` (or `dist:mac`/`dist:linux`), the bundled Node.js runtime was not included. This caused the error:

> "node is not recognized as an internal or external command"

The MCP server connections (Microsoft 365, GitHub) require npx to run, which in turn needs Node.js.

## Root Cause

The platform-specific build scripts (`dist:win`, `dist:mac`, `dist:linux`) were missing `npm run fetch-runtimes`, which downloads the portable Node.js runtime for bundling.

The generic `dist` script had it, but not the platform-specific ones:

```json
// Before (broken)
"dist:win": "npm run fetch-model && electron-vite build && electron-builder --win"

// After (fixed)
"dist:win": "npm run fetch-model && npm run fetch-runtimes && electron-vite build && electron-builder --win"
```

## Fix

Added `npm run fetch-runtimes &&` to all platform-specific build scripts in package.json.

## Notes

- CI release builds were unaffected (the workflow downloads runtimes explicitly)
- This only impacted developers building locally with platform-specific scripts
